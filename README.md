# hulkiciray.github.io

Personal website of Hulki Çıray, served by GitHub Pages at https://hulkiciray.github.io.

Plain HTML and CSS, no build step (`.nojekyll` turns Jekyll off).

- `index.html`: home page content
- `resume/index.html`: the resume as a web page; edit it there (it has a "Save as PDF" button)
- `assets/style.css`: styles (light and dark mode, plus the resume's print layout)
- `assets/site.js`: hero dot grid, clock and active-section marker
- `assets/Hulki_Ciray_CV.pdf`: old PDF CV, kept so existing links keep working; no longer linked from the site
- `cv/` and `portfolio/`: redirects from the old site's URLs

Preview locally:

```bash
python3 -m http.server 8000
```
