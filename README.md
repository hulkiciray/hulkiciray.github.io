# hulkiciray.github.io

Personal website of Hulki Çıray, served by GitHub Pages at https://hulkiciray.github.io.

Plain HTML and CSS, no build step (`.nojekyll` turns Jekyll off).

- `index.html`: all page content
- `assets/style.css`: styles (light and dark mode)
- `assets/Hulki_Ciray_CV.pdf`: the CV linked from the header
- `cv/` and `portfolio/`: redirects from the old site's URLs

Preview locally:

```bash
python3 -m http.server 8000
```
